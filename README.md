# 🚀 Galactic Defender - 2D Space Shooter

A 2D arcade space shooter game built using **HTML5 Canvas, CSS3, and Vanilla JavaScript** for the **Computer Graphics and Multimedia Systems** course project.

## 🎮 Features Implemented
- **Graphical 2D Canvas:** Custom vector graphics (polygons, arcs, gradients, and 2D transformations like translation & rotation) rendered at 60 FPS.
- **Dual Controls:** Smooth movement using either **Mouse** or **Keyboard (`Arrow Keys` / `A` & `D`)** with banking tilt animation.
- **Dynamic Enemies & Boss Battles:** Rotating asteroids, agile alien interceptors, and periodic Boss Dreadnoughts with health bars.
- **8 Power-Up Drops:**
  - `A` **Plasma Ammo:** Unlocks dual high-damage wing lasers.
  - `M` **Multi-Shot:** Fires 3 parallel laser beams.
  - `W` **Spread Shot:** Fires a 5-way directional spread.
  - `R` **Rapid Fire:** Increases firing rate significantly.
  - `D` **2X Damage:** Doubles laser damage output.
  - `S` **Shield:** Protects the ship from enemy collisions.
  - `+` **Health Pack:** Restores +25% ship health.
  - `B` **Nuke Bomb:** Destroys all enemies currently on screen.
- **Progression & UI:** Live Score, Health, Plasma Ammo counter, Level progression with increasing speed, **Pause (`P`)** functionality, Start Menu, and Game Over screen with instant restart.
- **Synthesized Multimedia Audio:** Real-time laser, explosion, bomb, and power-up sound effects generated via the **Web Audio API** (zero external audio dependencies).

## 🕹️ Controls
- **Move Left / Right:** `Mouse` or `Left/Right Arrow Keys` or `A / D`
- **Shoot:** Automatic continuous fire
- **Pause / Resume:** `P` key or click the `PAUSE (P)` button

## 🛠️ How to Run
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox) or run via VS Code **Live Server**.
